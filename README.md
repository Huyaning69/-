# 英汉速查

一个轻量的 Windows 桌面词典小工具：输入英文单词/短语或中文，立刻看到中文释义或英文近义词。
A tiny Windows desktop dictionary tool: instant Chinese meanings for English words/phrases, and English synonyms for Chinese words.

## 功能

- **英译中**：输入英文单词或短语（如 `look after`、`give up`），显示音标与中文释义；短语会标注「短语释义来源」。
- **中译英**：输入中文（如 `美丽`），列出多个英文候选词、词性，并给出简短辨析。
- **自动查询**：停止输入约 0.35 秒后自动查询，也可以按 `Enter` 或点击「查询」立即查询。
- **内存缓存**：重复查询同一条目直接命中缓存，响应更快。
- **单实例运行**：重复启动只会唤出已有窗口，不会开出第二个界面。
- **全局快捷键**：`Ctrl + Alt + E` 唤出并置顶窗口，`Ctrl + Alt + M` 最小化窗口。

## 运行

```powershell
pythonw 英汉速查.pyw
```

也可以直接双击 `英汉速查.pyw`（`.pyw` 扩展名表示不弹出控制台窗口）。

环境要求：**Windows 10/11 + Python 3.10 或更高版本**（开发测试环境为 Python 3.14）。只使用标准库，无第三方依赖；仅支持 Windows，因为快捷键依赖 Win32 API。

### 让快捷键在程序未运行时也能启动

1. 右键 `英汉速查.pyw` → 「发送到」→「桌面快捷方式」。
2. 右键该快捷方式 → 「属性」→「快捷键」，按下 `Ctrl + Alt + E`。
3. 之后按 `Ctrl + Alt + E`：程序未运行则启动，已运行则唤出并置顶。

## 关于全局键盘钩子

程序通过 Win32 `SetWindowsHookExW`（`WH_KEYBOARD_LL`）安装一个**全局键盘钩子**，仅用于识别 `Ctrl + Alt + E` 与 `Ctrl + Alt + M` 两个组合键。它**不记录、不存储、不上传任何按键内容**，其它按键一律 `CallNextHookEx` 直接放行。

如果你不需要快捷键，可删除 `DictionaryApp.__init__` 里的 `self._start_hotkey_listener()` 调用。

## 数据来源与隐私

- 查询通过 HTTPS 发送到第三方词典接口：`https://dict.youdao.com/jsonapi`（有道词典的网页接口）。
- **你输入的内容会离开本机**并发送给该第三方服务。本程序不把任何查询记录写入磁盘，仅在内存中缓存，退出即失效。
- 该接口既不是牛津词典的授权数据，也不是有道的公开 API 文档接口，可能随时变更或失效。
- 本项目仅供个人学习与自用，请勿用于商业用途或高频批量抓取；释义内容的版权归原数据服务方所有，本项目不附带、不再分发任何词典数据。
